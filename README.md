# VELORA • FreeCell

A digital masterpiece reimagining the 1978 PLATO classic for the modern connoisseur.

## Philosophy
We approached this not as another solitaire clone, but as a luxurious interactive artifact. Every transition uses custom cubic-bezier timing. Card stacking respects real physics offset. The LCG implementation is bit-exact to Jim Horne’s original Microsoft release.

## Features
- Pixel-perfect deal reproduction for seeds 1–1,000,000+
- Fluid drag & drop with multi-card support
- Real-time move validation using alternating color descending rules
- Foundations auto-build with suit sequencing
- Elegant win-state orchestration with particle celebration

## Built With Intention
- Vanilla HTML5, CSS3 (custom properties, backdrop-filter, advanced shadows)
- Pure ES6+ JavaScript with module-like encapsulation
- Zero dependencies beyond Font Awesome for icons
